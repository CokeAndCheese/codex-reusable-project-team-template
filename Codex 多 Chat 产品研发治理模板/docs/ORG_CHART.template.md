## 3. 决策与汇报关系

- 用户处理产品方向、范围、重大架构取舍、风险接受、人事和发布决策。
- 产品经理吸收日常研发协调；决策获批后自行拆解、调度和验收。
- 研发角色不向用户上抛日常技术细节；超出授权的重大风险由产品经理升级。
- 技术负责人提供架构裁决建议；产品范围和最终验收由产品经理管理。
- QA 独立于实现者，发布建议不能只依赖开发者自测。
- 团队共享同一工作区，但代码和文档写入进入单一队列；只读审查可并行。
